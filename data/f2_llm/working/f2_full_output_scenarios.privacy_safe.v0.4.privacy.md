# F2 full-output 합성 데이터 개인정보 기록

## 생성과 이용 범위

- 실제 상담, 운영 DB, 외부 데이터와 사람 정보를 읽지 않는 결정적 Python 생성기로 만들었다.
- F2의 상담 유형, 장부 불일치, 필드 추출, 원문 근거와 상담 로그 초안 검증에만 사용한다.
- 데이터와 정답은 사람이 검수하지 않은 초안이며 정식 골드 평가나 운영 성능 주장에 사용하지 않는다.

## 합성·비식별 통제

- 지명, 단지명, 사람 이름과 중개업소명은 생성기 안의 명백한 합성 슬롯만 사용한다.
- 전화번호 형태가 필요한 필드는 고정 placeholder `010-1234-5678`만 사용한다.
- 모든 행은 `contains_real_personal_data: false`와 `review_status: generated_unreviewed`를 가진다.
- 개인정보 동의 여부는 AI가 추론하면 안 되는 필드이므로 정답에 생성하지 않는다.
- 실제 개인정보와 연결되는 재식별 표는 존재하지 않는다.

## 저장·외부 처리·삭제

- 검수 전 작업 산출물로 Git 저장소의 `data/f2_llm/working/`에 보관한다.
- 접근 주체는 프로젝트 저장소 접근 권한이 있는 팀원이다.
- RunPod 학습을 명시적으로 실행하면 합성 transcript가 해당 실험 환경에서 처리될 수 있다.
- working 초안은 사람 검수 결과에 따라 새 불변 버전으로 발행하거나 반려·삭제한다.

## 남은 한계

- 자동 검사는 합성 슬롯이 실제 세계의 사람이나 장소와 우연히 같은지를 증명하지 않는다.
- 템플릿 기반 문장은 실제 STT 오류와 실제 상담 분포를 대표하지 않는다.
- 문자 길이만 자동 검사했으며 Qwen tokenizer 기준 토큰 길이는 RunPod 학습 전에 확인해야 한다.
- 정답 필드, evidence와 summary는 사람이 확인하기 전까지 검수 완료 라벨이 아니다.
