## 9. Matrix 확정 후 남은 비화면 논점

Screen Matrix는 확정한다. 다음 항목은 화면 수·소유·이동을 바꾸지 않는 데이터·운영 논점으로 분리한다.

- F1-PG-070 보류 목록의 F1 수신 요구사항 ID 신설
- 손님 상세의 필드 순서·액션 요구사항 세부화
- F3 포지션 정정 로그 스키마
- 개인정보 보유·파기 기간
- 음성 원본·STT 전문의 F1 장기 보존 여부·기간과 업로드 용량 상한. 값이 확정되기 전 프로토타입은 임의 상한을 제품 규칙으로 사용하지 않음
- F3 교차 판정을 저장·상세 열기에서 자동 실행할지, 사용자가 [교차 매칭]으로 실행할지. F3-CR-01~04와 prototype이 달라 PO 결정 전에는 어느 방식도 확정하지 않음
- F2 로컬 LLM과 F3 모델의 자원 경합
- 상담 로그의 `주` 표기 의미 (`①②③`은 인물 순번으로 해소)
