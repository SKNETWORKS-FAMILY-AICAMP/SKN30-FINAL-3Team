# F1 상담 로그

### 7. 상담 로그

F1에서 가장 많이 쓰이고, F3가 가장 많이 읽는 데이터.

#### 7.1 로그 데이터 규격

##### 포맷 규격

```
매물장   [26-05-19 17:50 주②]동남에서 매매물건받음      ← 마커가 괄호 안
구입장   [26-08-07 13:37]②정부발표가 1주택자도…        ← 마커가 괄호 밖

두 장부의 표기가 다르다. 파서는 양쪽을 모두 받아야 한다.

「주」  = 상대 역할 (주인 / 세입자 등)
「②」  = 인물 인덱스. 같은 역할에 사람이 여럿일 때의 순번 (남편 ①, 아내 ②)
        → 통화 회차나 발신·수신이 아니다. 인터뷰로 확정 (17.2)
```

> **[주의]** **현행 화면에서 관찰된 필드 오용** — 캡처에서 `붙박이` 칸에 설비가 아니라 **다른 세대의 세입자 정보**가, `비고` 칸에 **동·호**가 적혀 있다. 사용자1에는 `조합`이 들어 있다. **적을 자리가 없으면 가장 가까운 빈 칸에 적힌다.** 이런 값은 원문을 그대로 보존하고, 정식 필드가 필요한지 인터뷰로 확인한다.

> **[주의]** **개인정보 유입 경로** — 현행 상담 로그 본문에 주민번호 앞 7자리가 그대로 적혀 있다 (`5898/연결이되지않아멘트`, `550125-1`). 로그 본문은 자유 텍스트라 구조적으로 막을 수 없으므로, **입력 시 패턴 탐지 후 경고**한다 (F1-SE-05).
