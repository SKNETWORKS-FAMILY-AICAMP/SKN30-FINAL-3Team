# F1 매물장 그리드

### 3. 매물장 그리드

현행 장부의 기본 화면 대응. F1의 중심 화면이다.

#### 3.1 표시

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-GR-01 | 세대 전수 표시 | 매물이 아닌 세대도 행으로 표시한다. 매매·전세·월세 칸이 모두 빈 행이 다수 존재하는 것이 정상이다 | 필수 | 매물장 |
| F1-GR-02 | 전 컬럼 기본 표시 | 13장에 정의된 33개 컬럼을 **기본값으로 모두 표시**한다. 최초 진입 시 숨겨진 열이 없어야 하며, 사용자가 열 숨기기로 줄인 경우에만 그 설정을 담당자별로 기억한다 | 필수 | 매물장 |
| F1-GR-03 | 행 수 무제한 | 현행 장부는 "검색결과 7200개만 보임" 경고가 뜬다. 본 시스템은 상한을 두지 않는다 | 필수 | 매물장 |
| F1-GR-04 | 건수 표시 | 현재 필터 조건에 해당하는 행 수를 상시 표시한다 | 필수 | 매물장 |
| F1-GR-05 | 행 고정 높이 | 상담 컬럼은 최신 1건만 1줄로 표시한다. 전체 이력은 상세에서 본다 | 필수 | 신규 |
| F1-GR-06 | 공동명의 단일 행 | 명의자가 2인 이상이어도 세대당 1행. 임대인 칸에 `박이서, 송경련` 형태로 접어 표시하고 공동명의 표식을 붙인다 | 필수 | 세대상세 |
| F1-GR-07 | 거래 유형 색상 | 현매물 값에 따라 셀 배경색을 달리한다 (매매·전세·월세) | 필수 | 매물장 |
| F1-GR-08 | 사용자 지정 색상 | 특정 셀·행에 사용자가 배경색을 지정할 수 있다. 현행 장부의 「바탕색」 개념 | 권장 | 구입장 |
| F1-GR-09 | 금액 표기 변환 | 저장은 원 단위, 표시는 억·만 단위. `2150000000` → `21.5억` | 필수 | 신규 |
| F1-GR-10 | 장부 구분 탭 | 아파트 / 상가 / 주택 / 재건축 탭을 제공한다 | 권장 | 매물장 |

#### 3.2 컬럼 조작

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-GR-11 | 컬럼 순서 변경 | 헤더 드래그로 순서를 바꾼다. 현행 장부의 「필드순서 변경」 대응 | 필수 | 매물장 |
| F1-GR-12 | 컬럼 순서 저장 | 변경된 순서를 담당자별로 저장하고 재접속 시 복원한다. 사용자마다 보는 컬럼이 다르다 | 필수 | 매물장 |
| F1-GR-13 | 컬럼 프리셋 | 기본(12) / 임대차 / 매물화 / 전체(33) 프리셋을 한 번에 전환한다. 33컬럼 상시 노출은 웹에서 사용 불가 | 필수 | 신규 |
| F1-GR-14 | 열 간격 조절 | 헤더 경계를 드래그해 **열 사이의 간격(너비)**을 조절한다. 조절 중 경계선을 실시간 표시하고, 결과를 담당자별로 저장해 재접속 시 복원한다 | 필수 | 신규 |
| F1-GR-37 | 너비 자동 맞춤·초기화 | 헤더 경계를 더블클릭하면 해당 열의 최장 값에 맞춰 자동 조절한다. 전체 열 너비를 기본값으로 되돌리는 [초기화]를 제공한다. 고정 열(F1-GR-15)도 동일하게 조절된다 | 권장 | 신규 |
| F1-GR-15 | 컬럼 고정 | 단지·동·호를 좌측 고정해 가로 스크롤 시에도 식별 가능하게 한다 | 필수 | 신규 |
| F1-GR-16 | 가로 이동 버튼 | 「화면 좌우 이동」 대응. 컬럼 단위로 가로 스크롤을 점프한다 | 선택 | 매물장 |

#### 3.3 필터·정렬

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-GR-17 | 컬럼별 필터 | 모든 컬럼 헤더에 필터를 제공한다. 텍스트·숫자·날짜 유형별로 조건을 달리한다 | 필수 | 매물장 |
| F1-GR-38 | 값 목록 표시 | **열 이름 옆에 목록 버튼**을 두고, 클릭하면 **해당 열에 실제로 존재하는 값 전체**를 목록으로 표시한다. 값 목록은 미리 정의된 코드가 아니라 **현재 데이터에서 추출**한다. 다른 필터가 걸려 있으면 그 결과 범위 안의 값만 열거한다 | 필수 | 신규 |
| F1-GR-39 | 중복 선택 | 목록의 값을 **복수로 선택**할 수 있다. 선택된 값에 해당하는 행만 화면에 표시하며, 선택은 OR 조건으로 결합한다. [전체 선택] [전체 해제]를 제공하고, 선택 상태를 필터 해제(F1-GR-18) 전까지 유지한다 | 필수 | 신규 |
| F1-GR-40 | 목록 내 검색·정렬 | 값이 많은 열에서는 목록 안에서 검색해 좁힌다. 값은 오름차순 정렬을 기본으로 하되 숫자·날짜는 자연 정렬한다. 값마다 **해당 건수**를 함께 표시한다 | 권장 | 신규 |
| F1-GR-41 | 빈 값 항목 | 값이 없는 행을 고를 수 있도록 목록에 **「(비어 있음)」 항목**을 별도로 둔다. 매물이 아닌 세대가 다수 존재하므로(F1-GR-01) 빈 값 선택은 실사용 조건이다 | 필수 | 신규 |
| F1-GR-18 | 모든 필터 해제 | 버튼 하나로 전체 필터를 초기화한다 | 필수 | 매물장 |
| F1-GR-19 | 컬럼 정렬 | 헤더 클릭으로 오름·내림차순 정렬. 다중 컬럼 정렬 지원 | 필수 | 매물장 |
| F1-GR-20 | 기본 정렬 | 동·호 오름차순으로 되돌린다 | 필수 | 매물장 |
| F1-GR-21 | 입력순 정렬 | 등록 순서로 정렬한다 | 권장 | 매물장 |
