#### 13.3 값 정규화 규칙

| 현행 표기 | 변환 |
|---|---|
| `만=27, 기=07, 일=26` | 2027-07-26 (2자리 연도는 2000년대로) |
| `9,45` / `28,8` | 억 단위 소수 → 945,000,000 / 2,880,000,000 원 |
| `380` (차임) | 만원 단위 → 3,800,000 원 |
| `550125-1` | 생년월일 6자리만 보존, 뒷자리 **폐기** |
| `에5` `에폴` | 원문 보존 + 에어컨 대수 파싱 |
| `매환24.04.20 18.7억` | 거래 완료일 2024-04-20, 거래가 1,870,000,000 |
| `대송 597-8988` | 중개업소 마스터로 분리 |
| `28억선` `3억미만` | 원문 보존 + 예산 상·하한 파싱 |

#### 13.4 신설 데이터 항목
