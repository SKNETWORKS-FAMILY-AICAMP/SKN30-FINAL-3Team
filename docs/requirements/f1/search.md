# F1 검색 및 호출

### 4. 검색 및 호출

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-SR-01 | 동-호 호출 | `101 203` 또는 `101-203` 입력 후 Enter → 해당 행으로 즉시 이동·선택·상세 표시 | 필수 | 매물장 |
| F1-SR-02 | 통합 검색 | 전 컬럼과 상담 로그 본문을 대상으로 하는 단일 검색창. 성명·전화번호·단지·메모 어디에 있어도 찾는다 | 필수 | 매물장·구입장 |
| F1-SR-03 | 전화번호 검색 | 하이픈 유무·부분 입력 모두 매칭한다. 걸려온 번호를 붙여 넣어 즉시 조회하는 용도 | 필수 | 인터뷰 |
| F1-SR-04 | 재호출 | 최근 조회한 세대·손님 목록을 유지하고 한 번에 되돌아간다 | 권장 | 매물장·구입장 |
| F1-SR-05 | 색상값 검색 | 사용자가 지정한 배경색을 기준으로 검색한다. 현행 장부의 「색상값 검색」 대응 | 선택 | 매물장 |
| F1-SR-06 | 상담 로그 검색 | 로그 본문 전문 검색. 기간·담당자·결과(통화/부재중)로 좁힐 수 있다 | 필수 | 신규 |
| F1-SR-07 | 동호 추가 | 장부에 없는 세대를 신규 등록한다. 동·호 입력 시 중복을 검사한다 | 필수 | 매물장 |
| F1-SR-08 | 단지 일괄 생성 | 동 범위·층수·라인 수를 입력하면 세대를 일괄 생성한다. 신규 단지 도입 시 수기 입력 방지 | 권장 | 신규 |
