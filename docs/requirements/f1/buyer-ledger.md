# F1 구입장

### 6. 구입장

수요측 대장. 매물장과 대칭 구조를 갖되 컬럼과 조작이 다르다.

#### 6.1 그리드

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-DM-01 | 구입장 그리드 | 13장에 정의된 17개 컬럼을 표시한다. 필터·정렬·인라인 편집은 매물장과 동일 | 필수 | 구입장 |
| F1-DM-02 | 기간 필터 | 「3개월 이내만 보기 / 모두 보기」 토글. 기간은 선택 가능하게 확장한다 | 필수 | 구입장 |
| F1-DM-03 | 구분 색상 코딩 | 매수·매도·전세·월세를 색으로 구분한다. 그리드와 상세 양쪽에서 유지한다 | 필수 | 구입장 |
| F1-DM-04 | 만기 도래일 보기 | 만기 임박 순 정렬 뷰로 즉시 전환한다 | 필수 | 구입장 |
| F1-DM-05 | 담당자 필터 | 본인 담당 건만 보기를 원클릭으로 전환한다 | 필수 | 구입장 |
| F1-DM-06 | 손님 추가·삭제 | 그리드에서 직접 추가·삭제한다. 삭제는 소프트 삭제로 복구 가능해야 한다 | 필수 | 구입장 |
| F1-DM-07 | 정렬 기준 분리 | 현행 장부는 접수일을 오늘로 덮어써 최근 건을 위로 올린다. 본 시스템은 **접수일과 최종접촉일을 분리**하고 정렬은 후자를 쓴다 | 필수 | 손님입력 |

#### 6.2 손님 입력

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-DM-08 | 별칭 입력 | 구입자는 실명이 아닌 별칭을 허용한다. "인천사모님" "414동세입자" "30억이하 엄마" 등 실사용 패턴이다 | 필수 | 구입장 |
| F1-DM-09 | 오늘 버튼 | 날짜 필드에 [오늘] 원클릭 입력을 제공한다 | 필수 | 손님입력 |
| F1-DM-10 | 2년후 버튼 | 만기일에 [2년후 오늘] 원클릭 계산을 제공한다. 주택임대차 기본 2년 | 필수 | 손님입력 |
| F1-DM-11 | 원문·파싱값 병존 | 금액·평형·이사일은 원문 문자열과 파싱값을 함께 저장한다. "28억선" "1~2억(보증금)" "1월중" 등을 잃지 않는다 | 필수 | 구입장 |
| F1-DM-12 | 복수 평형 | 희망 평형을 복수로 입력한다. `25 33` `18 21` | 필수 | 구입장 |
| F1-DM-13 | 진행단계·완료여부 | 두 필드는 별개다. 진행단계는 자유 입력, 완료여부는 진행/완료 선택 | 필수 | 손님입력 |
| F1-DM-14 | 저장 시 날짜 갱신 | 「저장 시 무조건 오늘 날짜로」 옵션을 제공하되, 기본값은 꺼짐. F1-DM-07과 충돌하므로 최종접촉일에만 적용한다 | 선택 | 손님입력 |
| F1-DM-15 | 분류·비고 | 사무소가 정의하는 분류 값과 자유 비고를 제공한다 | 권장 | 구입장 |
| F1-DM-16 | 동의 없이 저장 불가 | 개인정보 활용 동의 미체크 시 저장 버튼을 막는다 (12장) | 필수 | 손님입력 |
