# F1 사용법 및 비기능 기준

### 14. 사용법 가이드

현행 장부는 도움말 동영상으로 사용법을 전달한다. 본 시스템은 **화면 안에서** 대체한다.

> **[참고]** **가이드는 부가 기능이 아니다.** 「경신」「월환」「에폴」처럼 **이 사무소에서만 통하는 표기**가 데이터에 실재한다. 담당자가 바뀌거나 인력이 늘면 이 표기를 읽을 수 없다. 용어 설명은 시스템이 데이터와 함께 보관해야 할 정보다.

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F1-HP-01 | 화면별 도움말 | 각 화면 우상단에 [도움말]을 두고 해당 화면의 조작 순서를 표시한다. 현행 장부의 화면 구성과 대응 관계를 함께 보여 준다 | 필수 | 신규 |
| F1-HP-02 | 용어·필드 툴팁 | 「경신」「월환」「명도」「붙박이」 등 현업 용어와 축약 표기에 툴팁을 붙인다. 설명 문구는 마스터에서 사무소가 직접 편집한다 (F1-MD-06과 연결) | 필수 | 신규 |
| F1-HP-03 | 최초 접속 안내 | 첫 로그인 시 핵심 조작(동-호 호출 · 인라인 편집 · 상세 로그 · 행 추가 · 문자 발송)을 순서대로 안내한다. 「다시 보지 않기」를 제공한다 | 권장 | 신규 |
| F1-HP-04 | 단축키 안내 | 키보드 조작 목록을 한 화면에서 조회한다. 그리드 이동·편집 확정·취소·검색 진입을 포함한다 (F1-GR-24) | 권장 | 신규 |
| F1-HP-05 | 검색 가능한 매뉴얼 | 기능별 사용법 문서를 시스템 안에서 검색·조회한다. 동영상 없이도 자력으로 찾을 수 있어야 한다 (16장 대체 수단) | 권장 | 신규 |
| F1-HP-06 | 빈 화면 안내 | 검색 결과 없음 · 로그 없음 · 발송 대상 없음 등 빈 상태에서 다음에 할 행동을 안내한다. 빈 화면은 가장 자주 보는 도움말이다 | 권장 | 신규 |
| F1-HP-07 | 변경 사항 안내 | 기능이 추가·변경되면 접속 시 요약을 1회 표시한다. 사용자가 바뀐 것을 모르고 쓰는 상황을 막는다 | 선택 | 신규 |

### 15. 비기능 기준

| ID | 항목 | 기준 | 등급 |
|---|---|---|---|
| F1-NF-01 | 그리드 로딩 | 7,200행 × 33컬럼 초기 표시 3초 이내 | 필수 |
| F1-NF-02 | 스크롤 반응 | 가상 스크롤로 화면 내 행만 렌더. 스크롤 시 끊김이 없어야 한다 | 필수 |
| F1-NF-03 | 검색 응답 | 동-호 호출 및 통합 검색 1초 이내 | 필수 |
| F1-NF-04 | 편집 반응 | 셀 편집 결과가 즉시 화면에 반영. 서버 왕복을 기다리지 않는다 | 필수 |
| F1-NF-05 | 확장성 | 단지 다수·10만 행 규모에서도 동작 구조를 유지한다 | 권장 |
| F1-NF-06 | 동시 편집 | 두 담당자가 같은 레코드를 편집할 때 나중 저장이 앞선 변경을 덮어쓰지 않는다 | 필수 |
| F1-NF-07 | 브라우저 | Chrome·Edge 최신 2개 버전. 데스크톱 우선, 모바일은 조회만 | 필수 |
| F1-NF-08 | 한글 입력 | 모든 입력 필드에서 한글 조합 중 데이터 손실이 없어야 한다 | 필수 |
| F1-NF-09 | 백업 | 일 1회 이상 자동 백업. 시점 복구가 가능해야 한다 | 필수 |
| F1-NF-11 | 팝업 응답 | 상세 로그 팝업은 0.3초 이내에 뜨고, 본문 로딩은 1초 이내에 끝난다. 로딩 중 그리드는 잠기지 않는다 (F1-LG-16) | 필수 |
| F1-NF-12 | 단체 발송 처리 | 수신자 500건 기준 목록 구성·중복 제거·치환 미리보기가 2초 이내에 끝난다 | 권장 |
| F1-NF-13 | 모바일 조회 범위 | 모바일에서 지원하는 화면을 **동-호 호출 · 세대/손님 상세 조회 · 상담 로그 조회 및 추가 · 문자 발송**으로 한정한다. 그리드 편집은 데스크톱 전용이다 | 필수 |
| F1-NF-14 | 네트워크 복원 | 연결이 끊겨도 미저장 변경분을 잃지 않고, 복구 시 자동 재전송한다 (F1-GR-35) | 필수 |
