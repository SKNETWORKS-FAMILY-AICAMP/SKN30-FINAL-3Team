# 챗봇 기획 요청 원문

사용자 제공 원문의 변경 금지 스냅샷이다. 검토 결과는 이 파일을 수정하지 않고 분할 정본에 반영한다.

> 새로운 기능 챗봇을 기획하려합니다.
>
> 기능
> - f2, f3 에이전트 연동 (f3 연동은 개발 시 보류)
> - 자연어 쿼리
>   - 그 외 db기반 기능
> - 부가 기능 (필수 아님)
>   - 시세분석 (공공 api 서칭 필요)
>
> 사용 llm
> - 범용 llm (로컬 gpt luna, dev qwen 27b)
>
> 화면
> - 구체화 필요
> - 우측하단 플로팅 챗버튼 클릭 시 활성화
> - 첫화면에서 소개 및 '이런 걸 물어보세요' 버튼 목록을 통해 기능 진입점 제공
> - sse 필요 진행 상황 및 검색 중인 것 화면 표기
> - 멀티턴 검토, 구현 불가 혹은 복잡성 높을 시 화면 안내 (예: 최대 2번의 대화만 기억 가능해요)
>
> 도입 근거, 구현가능성, 복잡성, 확장성, 사용할 기술 스택, 문서 정리 위치
>
> 등 검토하여 제안, [requirements](../index.md) [screen](../../screen/index.md) [architecture](../../architecture/index.md) 등 문서 필독
