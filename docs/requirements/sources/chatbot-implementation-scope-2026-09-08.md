# F4 챗봇 구현 승인과 평가 범위

사용자는 합의된 설계를 코드로 구현하고 격리된 로컬 검증 후 PR을 제출하도록 요청했다.

- 매물·구입장·할 일 조회, F2 기존 화면 연결, 대화 저장·복원과 작성자 전체 삭제를 구현한다.
- 현재 조건과 직전 완료된 질문·답변 2쌍을 사용한다. 화면 종료 뒤 서버 처리를 계속하고 서버 중단은 수동 재시도한다.
- 주 에이전트와 최대 3개 서브에이전트가 AI·Backend·Frontend를 분담하며, 작성자와 다른 에이전트가 데이터·실행, AI·조회, UI·통합을 교차 검토한다.
- 실제 DB·모델 정확도·안전성·warm 성능 검증을 필수로 한다. 팀원 사용성 평가는 완료 조건에서 제외한다.
- AI 계약, Backend 저장·조회·API, 화면·통합을 의존 PR 3개로 나누고 모두 `dev`를 대상으로 한다. 저장소의 사람 검토 정책을 유지한다.
- 공유 dev DB 변경·배포·새 GPU 기동은 이번 작업에 포함하지 않는다.

모델 접속 정보 요청에 대한 후속 답변에서 사용자는 개인 OpenAI 키를 `ai/.env`에 준비했으며, Qwen은 RunPod 기동이 필요하므로 **우선 보류하고 OpenAI로 구현을 진행**하도록 지시했다. 따라서 Luna 실제 검증은 계속하고 Qwen 결과는 미실행으로 기록한다. 비밀값은 이 문서에 포함하지 않는다.

이 기록은 사용자 작업 승인이며 팀의 PR 병합 승인이나 공유 환경 적용 완료를 의미하지 않는다. 구현·검증의 현재 상태는 [검증 정본](../../architecture/chatbot/implementation-and-validation.md)에서 관리한다.
