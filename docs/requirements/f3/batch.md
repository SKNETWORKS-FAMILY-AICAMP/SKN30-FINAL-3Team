# F3 배치 판정

### 11. 배치 판정 — 캠페인

문자 발송은 판단 대상이 아니라 도구다. 우선순위 큐에 넣지 않는다.

```text
[1] 대상 선정 — SQL                                 LLM 0회
    "헬리오 33평 임대인 중 6개월 미접촉"           →  104명
[2] 대리 배치 실행 — 얕은 판정                       LLM 104회 (병렬, 캐시 히트 제외)
    매도 의향 표명한 적 있음        8명   → 지금이 적기
    만기 임박, 결정 앞둠           23명   → 계획 확인
    최근 명시적 거절               11명   → 발송 제외
    임차인이라 결정권 없음          6명   → 발송 제외
    접촉 이력 부족, 판단 불가       56명   → 일반 시세표
[3] 세그먼트별 문안                                  LLM 4회
[4] 미리보기 → 일괄 승인 → 발송
[5] 전원 상담 로그 자동 append → 재연락 주기 갱신
```

> **[참고]** **캠페인의 실제 가치는 17명을 빼는 것이다.** 최근 거절한 11명과 결정권 없는 6명은 로그를 읽어야 알 수 있다. 거절한 사람에게 또 보내면 관계가 상한다. 조건 세그먼트만으로는 이 판단이 불가능하다.

#### 11.1 대상 선정

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F3-BT-01 | 입력 방식 3종 | ① 필터 UI로 조건 지정 ② 그리드에서 행 선택 ③ 자연어 입력을 모두 지원한다 | 필수 | 설계서 |
| F3-BT-02 | 조건 세그먼트는 SQL | 대상 선정에 AI를 쓰지 않는다. 만기 3개월 이내 · 특정 단지 평형 · N개월 미접촉 등은 조회 조건이다 | 필수 | 설계서 |
| F3-BT-03 | 대상 확인 → 제외 → 판정하기 | 캠페인 진입 시 선정된 대상 수와 명단을 먼저 표시하고, 사용자가 개별 제외한다. 제외를 마친 뒤 **[판정하기] 버튼을 눌러야 판정이 시작**되며 화면 진입만으로 자동 실행되지 않는다. 포함 대상이 0건이면 버튼을 비활성화하고 사유를 표시한다. 제외는 이번 캠페인에만 적용되며 원본 선택 집합(F3-BT-01)을 바꾸지 않는다 | 필수 | 설계서 |
| F3-BT-04 | 대상 규모 경고 | 대상이 설정 상한(기본 200명)을 넘으면 경고하고 실행 전 확인을 받는다 | 권장 | 신규 |

#### 11.2 판정 세그먼트

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F3-BT-05 | 대리 단독 실행 | 배치 판정은 **한쪽 대리만 N회** 실행한다. 반대편이 없으므로 중개 판정을 쓰지 않는다 | 필수 | 설계서 |
| F3-BT-06 | 세그먼트 분류 | 판정 결과가 곧 세그먼트다. 매도 의향 표명 · 만기 임박 · 최근 거절 · 결정권 없음 · 판단 불가 등으로 분류한다 | 필수 | 설계서 |
| F3-BT-07 | 발송 제외 식별 | 최근 명시적으로 거절한 대상과 결정권이 없는 대상을 **발송 제외**로 분류하고 로그 근거를 함께 제시한다. **연락 동의가 X인 대상(F1-UD-28)도 발송 제외에 포함**하며, 이 판단은 AI가 아니라 세대 상세의 동의 표시 값을 그대로 읽는다 | 필수 | 설계서 |
| F3-BT-08 | 판단 불가 처리 | 접촉 이력이 부족한 대상은 억지로 분류하지 않고 「판단 불가」 세그먼트로 두어 일반 문안 대상으로 삼는다 | 필수 | 설계서 |
| F3-BT-09 | 얕은 판정 | 배치 판정의 대리 실행은 카드 전 항목을 채우지 않고 세그먼트 분류에 필요한 항목만 산출할 수 있다. 이 경우 얕은 판정임을 결과에 표시한다 | 권장 | 설계서 |
| F3-BT-10 | 병렬 실행과 캐시 | 대리 호출을 병렬로 실행하고 캐시 히트분을 제외한다. 진행률과 실제 호출 수를 표시한다 | 필수 | 설계서 |
| F3-BT-11 | 세그먼트 수정 | 세그먼트 분할 결과를 사용자가 수정한다. 그룹 병합·분리·대상 제외가 가능해야 한다 | 필수 | 설계서 |
| F3-BT-12 | 컷 없음 | 세그먼트 분류가 대상을 임의로 줄이지 않는다. 발송 제외를 제외한 대상 전원이 어느 세그먼트엔가 속한다 | 필수 | 설계서 |

#### 11.4 배치 + 교차 옵션 (P2)

유망 세그먼트에만 중개 판정을 덧붙여 문안의 설득력을 높인다. "현재 이 조건으로 매수 의사 있는 분이 2명 계십니다."

|---|---|---|---|---|
| F3-BT-21 | 선택 세그먼트 교차 | 선택한 세그먼트의 대상 각각을 앵커로 삼아 반대편 후보를 조회하고 교차 판정을 실행한다 | P2 | 설계서 |
| F3-BT-22 | 근거 실린 문안 | 교차 판정 결과를 문안 재료로 넘긴다. "조건 맞는 매수 희망자 2명" · "예산대가 형성되어 있다" | P2 | 설계서 |
