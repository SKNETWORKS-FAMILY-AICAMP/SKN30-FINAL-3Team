# F3 후보 추출·공유 도구

### 8. 후보 추출 및 대상 선정 — 코드

에이전트가 아니다. SQL이며 결정적이다.

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F3-SQ-01 | LLM 비사용 | 후보 추출과 캠페인 대상 선정에 LLM을 쓰지 않는다 | 필수 | 설계서 |
| F3-SQ-02 | 유닛 테스트 | 추출 조건을 유닛 테스트로 검증한다. 판정 품질과 무관하게 정확성이 보장되어야 한다 | 필수 | 설계서 |
| F3-SQ-03 | 추정값 반영 | 후보 추출 조건은 **장부 표기값이 아니라 앵커 카드의 추정값**을 쓴다. 표기 예산 28.5억이어도 추정 상한이 30억이면 30억 이하를 조회한다 | 필수 | 설계서 |
| F3-SQ-04 | 점수 산출 | 가격 근접도 · 평형 일치 · 접수 최신순으로 후보 점수를 산출한다. 점수는 순서 결정용이며 등급을 대신하지 않는다 | 필수 | 설계서 |
| F3-SQ-05 | 날짜 신호 산출 | 아래 날짜 신호를 SQL로 산출해 대리의 입력으로 넣는다. 신호 자체가 F3의 출력이 되지 않는다 | 필수 | 설계서 |
| F3-SQ-06 | 응답 시간 | 후보 추출 쿼리는 7,200행 이상 규모에서도 100ms 이내에 끝난다 | 필수 | 신규 |
| F3-SQ-07 | 자연어 대상 선정 | 캠페인 대상 조건을 자연어로 입력하면 조회 조건으로 변환한다. 변환 결과를 조건식으로 보여주고 사용자가 수정할 수 있어야 한다 (11.1) | 권장 | 설계서 |

#### 8.1 날짜 신호

| 신호 | 대리의 해석 |
|---|---|
| 임대차 만기 D-day | 보유자가 결정을 앞둔 상태. 매도·갱신·월세전환 중 선택해야 한다 |
| 계약일 · 중도금 · 잔금 | 이행 국면. 판정보다 절차 확인이 우선 |
| 거래신고 기한 | 법정 기한. F1 규칙 알림이 처리한다 |
| 이사일 | 손님 측 물건 확보 마감. 시급도의 결정 근거 |
| 광고 게시 후 경과 | 시장 반응 부재. 조건 재검토 여지 |
| 최종 접촉 후 경과 | 접촉 가능 상태 판정의 주요 근거 |

### 9. 공유 도구

에이전트가 호출하는 함수다. 도구 자체는 판단하지 않는다.

| ID | 요구사항 | 상세 | 등급 | 출처 |
|---|---|---|---|---|
| F3-TL-01 | 로그 검색 | 상담 로그 본문을 기간·상대·키워드로 검색한다. F3의 핵심 도구이며, 로그를 지우지 않고 누적하는 F1 정책이 여기서 자산이 된다 | 필수 | 설계서 |
| F3-TL-02 | 매물 조회 | 세대·매물의 구조화 데이터와 임대차 현황을 조회한다 | 필수 | 설계서 |
| F3-TL-03 | 손님 조회 | 손님의 희망 조건과 진행 단계를 조회한다 | 필수 | 설계서 |
| F3-TL-04 | 접촉 이력 | 최종 접촉일·접촉 수단·응답 여부를 조회한다 | 필수 | 설계서 |
| F3-TL-05 | 단지 정보 | 단지·평형·구조 등 공통 정보를 조회한다 | 권장 | 설계서 |
| F3-TL-06 | 도구 권한 분리 | 매물 대리는 손님 조회 도구를, 손님 대리는 매물 조회 도구를 호출할 수 없도록 **도구 수준에서 차단**한다. 프롬프트 지시만으로 격리를 보장하지 않는다 | 필수 | 신규 |
| F3-TL-07 | 호출 기록 | 모든 도구 호출을 실행 로그에 남긴다 (F3-CM-04) | 필수 | 설계서 |
