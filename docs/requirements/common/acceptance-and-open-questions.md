# 통합 완료 기준·미해결 사항

> **[결정 · 2026-08-17] 현재 MVP 완료 기준:** [현재 MVP 범위와 평가 중심](mvp-scope-and-evaluation.md)이 우선한다. 아래 0.9 기준 중 문자·일정·권한과 F1 전체 기능 완결성에 관한 항목은 이번 MVP 구현 게이트가 아니며 후속 제품 수용 기준으로 보존한다.

### 0.9 통합 완료 기준

각 부의 완료 기준에 더해, **세 기능이 하나로 동작하는지**를 보는 기준.

| # | 기준 |
|---|---|
| 1 | F1 그리드에서 행을 추가하고 F2 음성메모로 채운 뒤 저장하면, 그 행이 F3 교차 판정의 앵커 또는 후보가 된다 |
| 2 | F2가 생성한 상담 로그가 F3 대리 에이전트의 근거 원문으로 인용된다 |
| 3 | F3가 제안한 일정을 승인하면 F1 일정에 `F3` 주체 표시와 함께 생성된다 |
| 4 | F3 후보 패널의 [문자 보내기]가 F1의 개인 문자 발송 화면으로 초안과 함께 진입한다 |
| 5 | F2와 F3를 모두 중단해도 F1의 모든 기능이 정상 동작한다 |
| 6 | 사람 / F2 / F3가 만든 로그를 화면에서 구분해 볼 수 있다 |
| 7 | 같은 세대에 대해 F2 실행 → 로그 추가 → F3 포지션 카드가 재생성된다 (캐시 무효화) |
| 8 | 읽기전용 사용자에게 세 기능 모두 개인정보가 마스킹된 상태로 표시된다 |

### 0.10 통합 미해결 사항

각 부의 미해결 사항 중 **둘 이상의 기능에 걸치는 항목**만 여기 모은다.

| # | 질문 | 걸린 기능 | 우선 |
|---|---|---|---|
| 1 | 상담 로그 「주」 표기의 의미와 임차인 통화 표기 | F1 (상대 구분 값 목록) · F2 (로그 생성 포맷) · F3 (화자 구분) | 최우선 |
| 2 | 로컬 LLM과 F3 모델의 배치·자원 경합 | F2 · F3 | 최우선 |
| 3 | 거래가 성사되면 장부에 무엇을 어떻게 적는가 | F1 (상태 전이) · F3 (성사 이후 판정 제외 조건) | 최우선 |
| 4 | 개인정보 보유 기간 | F1 (파기 주기) · F2 (음성·STT) · F3 (실행 로그) | 높음 |
| 5 | 발신번호 사전등록 서류 준비 여부 | F1 (실발송 모드) · F3 (캠페인 발송) | 높음 |
| 6 | 상담 로그를 나중에 검색해서 찾아본 적이 있는가 | F1 (로그 검색 우선순위) · F3 (대리의 핵심 도구 가치 검증) | 높음 |
| 7 | 「만기도래일 보기」를 실제로 쓰는가 | F1 (알림 설계) · F3 (경계 — 목록은 F1, 판정은 F3) | 높음 |
| 8 | F2 입력 자동화와 F3 멀티 에이전트 비교에 사용할 평가 데이터셋, 지표 산식, 사람 평가 절차와 합격 임계값을 어떻게 확정할 것인가 | F2 · F3 (재현 가능한 AI 품질 검증과 MVP 완료 판정) | 최우선 |


### 0.11 해소된 항목

확인이 끝나 세 부의 요구사항에 반영된 항목. 되묻지 않기 위해 남긴다.

| 질문 | 확인 결과 | 반영 |
|---|---|---|
| 현행 장부 데이터 내보내기(엑셀·CSV)가 되는가 | **되지 않는다.** 내보내기 기능 자체가 없다 (2026-08-13) | 자동 이관 경로가 성립하지 않아 **데이터 이관을 범위에서 제외**했다. 초기 데이터는 사무소가 직접 입력하는 것을 전제한다 — 제1부 1.2 · 16장 |
| 상담 로그의 ①②③은 무슨 뜻인가 | **같은 역할에 인물이 여러 명일 때의 순번**이다 (예: 남편 ①, 아내 ②). 통화 회차나 발신·수신 구분이 아니다 (2026-08-13) | 제1부 2.1 용어 추가 · 7.1 포맷 규격 명시 · F1-LG-33 · F1-LG-34 신설. F3의 화자 구분 입력으로도 사용 |
| STT는 통화 중 실시간인가, 통화 후 파일 업로드인가 | **통화 후 파일 업로드만 지원한다.** 브라우저 내 직접 녹음도 제공하지 않는다 (2026-08-14 화면 검토) | 제2부 5.2 입력 기능에서 녹음 항목 삭제 · 9장 제외 범위에 「브라우저 내 직접 녹음」 추가 · F2-POP-03 신설 |
| 통화 녹음의 상대방 고지·동의를 어떻게 처리하는가 | **음성메모 팝업 진입 시 주의 문구를 표시하고 확인 체크를 받는 방식**으로 처리한다. 시스템이 내용을 검사해 수정을 안내하거나 저장을 막지 않는다 (2026-08-14 화면 검토) | 제2부 5.2 개인정보 주의 문구 · F1-SE-03 · F1-SE-05 개정 |
