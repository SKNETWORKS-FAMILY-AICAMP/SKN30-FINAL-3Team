# 현재 MVP 범위와 평가 중심

이 문서는 현재 MVP의 구현 범위와 우선순위 정본이다. 기존 F1·F2·F3 상세 요구사항과 충돌하면 이 문서의 범위 판단이 우선한다. 기존 상세 요구사항은 삭제하지 않고 후속 제품 백로그와 설계 참고로 보존한다.

## 범위 판단 기준

새 기능이나 기존 요구사항을 MVP에 넣을지는 다음 질문으로 판단한다.

> F2/F3 AI 기능을 시연하고 품질을 평가하는 데 필요한가?

필요성이 직접 설명되지 않는 일반 CRUD, 운영 편의, 현업 제품 완결성 작업은 MVP에서 제외하거나 시연에 필요한 최소 수준으로 축소한다. 구현 시간은 F2/F3 AI 파이프라인, 데이터셋, 실험, 오류 분석과 평가에 우선 배분한다.

## 기능별 MVP 범위

| 기능 | MVP 포함 | 이번 MVP에서 제외·최소화 |
|---|---|---|
| F1 최소 데이터 기반 | 장부 목록 조회, 행 추가, F2 승인 결과 저장, F3가 사용할 장부·상담 로그 조회 | 검색·필터·문자·일정·계약·권한·마스터 관리와 현업 수준 CRUD/UI. F2/F3 시연에 꼭 필요한 경우만 최소 구현 |
| F2 AI 입력 자동화 | 음성메모 업로드와 STT, 상담 유형 판단, 장부 필드 추출, 근거가 있는 AI 제안값 검토, 사용자 수정·승인 후 장부 반영 | AI의 무승인 자동 저장, 일반 장부 제품 기능 확장 |
| F3 멀티 에이전트 판단 | 장부와 상담 로그 기반 포지션 판단, 매물 대리, 손님 대리, 결정적 후보 추출, 양측 포지션 기반 중개 판정, 근거 제시, 사용자 피드백 | 문자 발송·일정·캠페인 등 판단 품질 검증에 직접 필요하지 않은 주변 제품 기능 |

## 유지하는 책임 경계

- F1은 F2/F3가 공유하는 데이터의 단일 원천이며 최소 저장·조회 인터페이스를 제공한다.
- F2는 음성을 구조화 제안으로 바꾸되 사용자 승인 전에는 F1의 확정 데이터로 만들지 않는다.
- F3는 F1의 장부와 상담 로그를 읽어 판단과 근거를 제안하며, 사용자 승인 없이 외부 행동을 실행하지 않는다.
- F2와 F3는 직접 결합하지 않고 F1에 저장된 데이터를 통해 연결한다.

## MVP 평가 초점

### F2

- STT와 상담 유형 판단, 필드 추출의 성능을 재현 가능한 데이터셋과 지표로 측정한다.
- 제안값의 근거, 누락, 오인식과 잘못된 필드 반영을 사용자가 검토할 수 있어야 한다.
- 사용자 승인 전후 데이터를 구분해 AI 자동 입력의 정확성과 수정 부담을 평가할 수 있어야 한다.

### F3

- 장부의 구조화 값과 상담 로그 원문을 근거로 각 측 포지션과 중개 판정을 제시한다.
- 후보 추출 정확도와 에이전트 판단 품질을 분리해 평가한다.
- 단일 프롬프트 기준선과 매물 대리·손님 대리·중개 판정 구조를 같은 사례에서 비교한다.
- 비교에는 근거 적합성, 걸림돌·양보 지점의 구체성, 중개 판정 품질과 사용자 피드백을 포함한다.

정확한 평가 데이터셋, 지표 산식과 합격 임계값은 별도 실험 계획에서 확정한다. 확정 전에는 임의의 수치를 승인된 기준으로 사용하지 않는다.

## 기존 요구사항의 해석

- 기존 상세 요구사항의 `필수` 등급은 장기 제품 정의 안에서의 중요도이며, 현재 MVP 포함을 자동으로 뜻하지 않는다.
- 현재 MVP 완료 여부는 F1의 현업 수준 완결성이 아니라 F2/F3 핵심 흐름의 종단 간 시연 가능성과 AI 품질 평가 가능성으로 판단한다.
- F1의 상세 검색·필터·문자·일정·계약·권한·마스터 관리 요구사항은 폐기하지 않지만 이번 MVP 구현 게이트로 사용하지 않는다.
