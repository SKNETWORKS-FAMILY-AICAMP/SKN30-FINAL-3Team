### 0.5 연동 접점 매트릭스

| 접점 | F1 측 | F2 측 | 비고 |
|---|---|---|---|
| 실행 진입 | F1-ST-01 버튼 이원 배치 (그리드 · 상세 로그 팝업) | F2-LIST-01 행 추가 → 상세 팝업 자동 오픈 | 두 경로의 결과가 같은 로그 레코드로 수렴해야 한다 |
| 신규 행 | F1-GR-30 빈 행 추가 · F1-ST-16 미선택 시 신규 행 | F2-LIST-01 상태 `임시저장` 부여 | 미저장 신규 행 정리는 F1-GR-32 · F1-ST-18 |
| 결과 표시 | F1-ST-15 비동기 팝업 · 음성메모는 별도 팝업 | F2-POP-03 음성메모 팝업 · F2-POP-01 현재값 · AI 제안값 비교 표시 | 자동 스크롤 인라인 표시 금지 |
| 반영 규칙 | F1-ST-06 덮어쓰기·추가 확인 · F1-ST-08 반영 전 미리보기 | F2-REV-02 빈 필드 기본 선택 · F2-REV-03 선택 항목 반영 | 기본 동작은 「내용 추가」 |

#### F2 ↔ F3 — 직접 접점 없음

F2와 F3는 서로를 호출하지 않는다. F2가 만든 상담 로그는 F1에 저장되고, F3는 그 로그를 F1에서 읽는다. **연결은 언제나 F1을 경유한다.**

> **[참고]** **이 구조가 주는 것.** F2가 만든 로그의 품질이 F3 판정의 품질을 결정한다. 「급하지 않음」 「본인 집이 팔려야 살 수 있다」 같은 비구조화 진술이 로그에 남아야 F3의 대리 에이전트가 조건표 너머를 읽을 수 있다. F2의 상담 로그 초안 생성(F2-REV-04)은 입력 편의 기능이 아니라 **F3의 원료 공급 장치**다.
