### 5.1 별도 화면을 만들지 않는 요구사항

아래 항목은 독립 화면이 아니라 기존 화면의 실행 조건·상태·감사·성능 규칙으로 반영한다.

## 6. 상태 Matrix

### 6.1 장부 저장 상태

| 상태 | 의미 | 목록 표시 | 주요 전환 |
|---|---|---|---|
| 임시저장 | 행이 생성·수정되었으나 사용자가 최종 저장하지 않음 | 미완성 행을 구분하고 이어서 작성·삭제 제공 | 최소 조건 충족, `변경` 항목 결정, 사용자 최종 확인 후 저장 완료 |
