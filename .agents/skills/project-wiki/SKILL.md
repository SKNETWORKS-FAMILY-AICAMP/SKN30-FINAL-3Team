# 프로젝트 위키

## 필요한 지식 찾기

1. [참조 인덱스](references/index.md)를 먼저 보고 현재 작업의 조건에 맞는 문서만 읽는다. 루트 `AGENTS.md`의 모듈 선택·결정 확인 규칙을 함께 따른다.
2. 요구사항은 [요구사항 인덱스](../../../docs/requirements/index.md)의 검색 의도와 ID 접두어로 찾는다. ID를 알면 `rg -n --glob '*.md' --glob '!**/sources/**' '<요구사항-ID>' docs/requirements`로 정본을 찾는다.
3. 계약 라우터에서는 공통 규칙과 수정할 기능의 계약만 읽는다. 모듈 간 변경이면 양쪽 계약을 확인한다.
4. 링크는 읽을 후보이지 재귀 탐색 지시가 아니다. 현재 컨텍스트에 내용이 있고 이후 파일이 바뀌지 않았다면 같은 문서를 다시 읽지 않는다. 내용이 없거나 변경 여부가 불확실하면 필요한 부분을 다시 확인한다.

아키텍처·정책 변경은 결정 인덱스와 관련 ADR, 미확정 사항에 의존하는 작업은 소유 범위의 `open-questions.md`를 확인한다. 출처 원문은 대조가 필요할 때만 읽는다.

## 상태와 소유권

- `출처`는 원문에서 확인한 정보, `결정`은 승인된 선택, `구현됨`은 코드·환경에서 확인된 상태다. `계획됨`·`제안`·`미확정`을 승인이나 완료로 바꾸지 않는다.
- 공통 아키텍처·계약·개인정보·개발환경은 project-wiki, 모듈 내부 구조·도구·패턴은 해당 모듈 references, 제품 요구사항은 `docs/requirements/`가 소유한다. 같은 내용을 복제하지 않고 정본에 링크한다.

## 지식이 바뀌었을 때

영구 지식이 생기면 코드와 같은 브랜치에서 소유 정본을 갱신한다. 편집 전에 [위키 운영 규칙](references/governance.md)의 갱신·ADR·출처 등록 절차를 읽는다. 임시 디버깅 기록과 확인되지 않은 추측은 정본에 넣지 않는다. Git 작업은 루트 `.agents-rule/git.md`를 따른다.
