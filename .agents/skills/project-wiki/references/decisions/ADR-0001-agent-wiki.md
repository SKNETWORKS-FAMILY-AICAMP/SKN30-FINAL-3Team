# ADR-0001: 프로젝트 지식을 스킬 위키로 관리

- 상태: 승인됨
- 결정일: 2026-08-12

## 맥락

사람은 기획서, WBS, 스프레드시트가 편하지만 에이전트가 같은 원문을 매번 읽으면 탐색과 토큰 비용이 크다.

## 결정

- `.agents/skills/project-wiki/`를 개발에 필요한 프로젝트 지식의 정본으로 사용한다.
- 사람용 원문과 에이전트용 위키를 분리한다.
- 에이전트는 개발 요청에서 확인된 영구 지식만 위키에 갱신한다.
- 루트 인덱스와 한 단계 분류를 사용해 필요한 문서만 읽는다.
- 위키는 코드와 같은 브랜치 및 PR로 관리한다.

## 결과

사람용 문서와 일부 내용이 중복될 수 있지만 각 독자에게 적합한 형식과 읽기 비용을 유지한다. 원문과 위키의 불일치는 출처 manifest와 PR 검토로 관리한다.
