# ADR-0002: 다섯 개 루트 모듈과 독립 환경 경계 사용

- 상태: 승인됨
- 결정일: 2026-08-12

## 맥락

서비스는 프론트엔드, 데이터 처리, API, 배치, 이벤트, 에이전트와 인프라를 포함할 수 있다. 모든 Python 기능을 하나의 백엔드 환경에 모으면 책임과 배포 경계가 흐려질 수 있다.

## 결정

- 루트 모듈을 `frontend`, `backend`, `agent`, `data`, `infra`로 둔다.
- 모듈 내부 상세 폴더 구조는 모듈별 스킬을 정리할 때 결정한다.
- 루트 공통 Python 환경과 `packages`를 초기 생성하지 않는다.
- Python 모듈은 각자 실행환경과 의존성을 관리한다.
- `data` 모듈에는 테스트 코드를 포함하지 않는다.

## 결과

초기 구조는 단순하게 유지하면서 모듈별 독립 배포 가능성을 확보한다. 공통 코드가 실제로 생기면 중복, 소유권과 버전 정책을 확인한 뒤 별도 결정을 내린다.
