# 프로젝트 개요

## 목표

특정 도메인에 종속되지 않고 데이터 처리, 웹 인터페이스, API, 비동기 작업, 멀티에이전트 실행과 클라우드 배포를 수용할 수 있는 MVP 개발환경을 구축한다.

현재 진행 중인 개별 기능 기획은 이 개발환경 위키의 확정 범위에 포함하지 않는다. 기능이 승인되어 개발 요청으로 들어오면 필요한 개발 지식만 위키에 추가한다.

## 팀과 기간 제약

- 팀원: 4명
- 우선순위: MVP와 단순한 운영
- AWS 예산: 2개월 합계 300,000원
- OpenAI API와 RunPod 비용이 위 AWS 예산에 포함되는지는 미확정

## 루트 모듈

| 모듈 | 책임 |
|---|---|
| `frontend/` | React 기반 사용자 인터페이스 |
| `backend/` | API, 배치, 이벤트 처리 등 일반 서버 기능 |
| `agent/` | 에이전트 그래프, 실행 상태, 모델·도구 연동 |
| `data/` | 데이터 수집, 가공, 품질 검증 |
| `infra/` | 클라우드 인프라 정의와 배포 구성 |

루트에 공통 `packages/`와 Python 실행환경을 미리 만들지 않는다. 실제로 둘 이상의 모듈에서 안정적인 공통 코드가 필요해질 때 별도 결정으로 검토한다.

## 문서 체계

- 사람용 문서: 기획서, WBS, 스프레드시트, 회의 자료
- 에이전트용 문서: `.agents/skills/project-wiki/`의 요구사항, 계약, 데이터 정의, 결정, 개발 규칙
- 사람용 원문을 자동으로 전부 읽거나 복제하지 않는다.
- 개발 요청에서 영구 지식이 생기면 에이전트용 위키를 함께 갱신한다.
