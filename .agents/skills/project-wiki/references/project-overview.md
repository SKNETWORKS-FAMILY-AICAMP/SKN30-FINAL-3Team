# 프로젝트 개요

## 목표

F1의 최소 장부 데이터 기반 위에서 F2의 AI 입력 자동화와 F3의 멀티 에이전트 중개 판단을 종단 간 시연하고 품질을 평가할 수 있는 MVP를 구축한다. 범위 판단의 정본은 [현재 MVP 범위와 평가 중심](../../../../docs/requirements/common/mvp-scope-and-evaluation.md)이다.

일반 장부 제품의 CRUD/UI 완결성보다 SLLM·ML/DL·멀티 에이전트 파이프라인과 AI 시스템 평가에 개발 시간을 우선 배분한다. 승인되지 않은 상세 기능은 확정 범위로 가정하지 않는다.

## 팀과 기간 제약

- 팀원: 4명
- 우선순위: MVP와 단순한 운영
- AWS 비용 참고 상한: 2026-09-23까지 누적 300,000원
- RunPod 예산: 2개월 합계 USD 300
- OpenAI API 예산: 2개월 합계 USD 300
- 세 한도는 서로 분리한다. 현재 AWS 계정에서는 Budget·Cost Anomaly Detection을 사용할 수 없어 AWS 한도는 자동 집행·알림이 아닌 운영 참고값으로 관리한다.

## 루트 모듈

| 모듈 | 책임 |
|---|---|
| `frontend/` | React 기반 사용자 인터페이스 |
| `backend/` | API, 배치, 이벤트 처리 등 일반 서버 기능 |
| `ai/` | AI 워크플로, 실행 상태, 모델·프롬프트·도구 연동 |
| `data/` | 데이터 수집, 가공, 품질 검증 |
| `infra/` | 클라우드 인프라 정의와 배포 구성 |

루트에 공통 `packages/`와 Python 실행환경을 미리 만들지 않는다. 실제로 둘 이상의 모듈에서 안정적인 공통 코드가 필요해질 때 별도 결정으로 검토한다.

## 문서 체계

- 사람용 문서: 기획서, WBS, 스프레드시트, 회의 자료
- 에이전트용 문서: `.agents/skills/project-wiki/`의 요구사항, 계약, 데이터 정의, 결정, 개발 규칙
- 사람용 원문을 자동으로 전부 읽거나 복제하지 않는다.
- 개발 요청에서 영구 지식이 생기면 에이전트용 위키를 함께 갱신한다.
