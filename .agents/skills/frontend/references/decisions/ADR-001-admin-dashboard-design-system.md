# ADR-001: 관리자 대시보드 디자인 시스템

## 맥락

관리자 콘솔, 운영 도구와 고밀도 표형 데이터 화면에서 일관된 애플리케이션 구조, 접근성 및 데이터 조작 경험이 필요하다. 현재 frontend에는 UI 의존성이나 구현이 없으므로 선택한 기준과 실제 구현 상태를 구분해야 한다.

## 결정

- 애플리케이션 셸, 탐색, 폼, 피드백과 일반 컴포넌트는 PatternFly 6을 기준으로 한다.
- 복잡한 표형 데이터 인터페이스는 AG Grid를 사용하고 단순 표는 PatternFly Table을 우선한다.
- AG Grid는 기본적으로 Community edition 범위에서 사용한다.
- Enterprise 전용 기능은 라이선스와 비용 승인을 별도로 받은 뒤 사용한다.
- 설치 버전의 정본은 frontend/package.json과 lockfile이다.
- 구체적인 UI 운영 규칙은 [design guide](../design/index.md)와 연결된 세부 가이드를 따른다.

## 결과

- AG Grid 테마를 PatternFly semantic token에 맞춰 하나의 제품 언어를 유지한다.
- 설치·업그레이드 시 토큰명, 컴포넌트 동작, 접근성과 라이선스 범위를 함께 검증한다.
- 의존성이 추가되기 전까지 이 결정은 선택된 개발 기준이며 구현 완료를 의미하지 않는다.
