# 데이터 모듈 결정 인덱스

| ADR | 상태 | 내용 |
|---|---|---|
| [ADR-0001](0001-dataset-lifecycle-layout.md) | 결정 | 루트 README, registry와 working·releases 생명주기 구조 |

데이터 저장 위치·포맷, 라벨링, 분할, 품질 도구와 실행환경은 [미해결 질문](../open-questions.md)에서 관리한다. 프로젝트 공통 데이터 계약, 개인정보와 평가 정책은 project-wiki가 소유한다.
