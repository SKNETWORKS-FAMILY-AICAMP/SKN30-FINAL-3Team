# ADR-0001: 데이터셋 생명주기 구조와 문서 위치

## 결정

- `data/README.md` 하나를 데이터 모듈 운영 규칙의 정본으로 사용한다.
- 데이터셋별로 README를 반복해서 만들지 않는다.
- 현재 데이터셋 산출물은 `working`, `releases/<version>` 생명주기로 관리한다.
- 데이터셋 목록과 최신 릴리스는 `data/registry.yaml`에서 관리한다.
- 공통 manifest 양식은 `data/manifest.template.yaml` 하나로 관리한다.
- 개별 릴리스의 출처, 분할, 개인정보, 체크섬과 한계는 해당 릴리스의 manifest가 소유한다.
- 원본 계층, 별도 스키마 또는 라벨 가이드는 실제 필요가 생길 때 추가한다.

## 이유

- 하위 README 간 중복과 불일치를 방지한다.
- 작업 중 산출물과 발행된 불변 데이터를 구분한다.
- 모델 실험이 사용한 데이터셋 버전과 계약을 재현할 수 있게 한다.

## 남은 결정

외부 저장 위치와 포맷, 라벨 검수 절차, 분할 접근 통제, 품질 도구는 기존 데이터 모듈 미해결 질문에서 계속 관리한다.
