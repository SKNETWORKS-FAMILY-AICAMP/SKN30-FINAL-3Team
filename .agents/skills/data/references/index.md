# 데이터 참조 인덱스

현재 작업에 필요한 문서만 읽는다. 기능별 요구사항과 필드 정의는 이 디렉터리에 복제하지 않고 프로젝트 요구사항 정본에서 확인한다.

| 문서 | 읽는 조건 |
|---|---|
| [dataset-design.md](dataset-design.md) | 데이터셋 목적, 사례 단위, 라벨, 분할, manifest, 버전과 배포 방식을 설계하거나 변경할 때 |
| [evaluation-design.md](evaluation-design.md) | 평가 질문, 지표, slice, 사람 평가, 기준선, 임계값과 비교 절차를 설계하거나 변경할 때 |
| [decisions/index.md](decisions/index.md) | 데이터 모듈 내부 구조·도구·포맷·품질 방식의 승인된 결정을 확인하거나 변경할 때 |
| [open-questions.md](open-questions.md) | 저장 위치, 포맷, 라벨링, 분할, 품질 도구 또는 평가 절차의 미확정 사항에 의존할 때 |

프로젝트 공통 요구사항, 데이터 계약, 개인정보 정책과 모듈 경계는 project-wiki를 확인한다.
