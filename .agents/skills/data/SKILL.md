# 데이터 스킬 초안

이 스킬의 구조와 개발 방식은 절대 규칙이 아니라 기본 권장안이다. 작업 규모와 위험에 맞는 가장 단순한 설계를 우선하고, 권장안에서 벗어난 이유와 검증 방법을 PR에 남긴다. 장기 유지할 모듈 내부 결정은 `.agents/skills/data/references/decisions/`에, 프로젝트 공통 결정·계약·정책은 project-wiki에 기록한다. 저장소 지침과 승인된 프로젝트·모듈 결정은 이 권장안보다 우선한다.

- 작업 위치: `data/`
- 주 언어 방향: Python
- 책임: 데이터 수집, 정제, 변환, 적재, 운영 데이터 품질 검증
- 테스트 코드는 `data/` 모듈에 포함하지 않음
- 입력 스키마, 필수값, 중복, 건수 등의 검증은 필요하면 운영 파이프라인 기능으로 구현
- 제외: 사용자 화면, 일반 API 서비스, 에이전트 그래프, IaC
- 데이터 실행환경과 의존성은 모듈 내부에서 독립 관리
- 데이터 출처, 이용 조건, 스키마, 개인정보 여부와 보존 방식을 기록
- 내부 폴더 구조, 저장 포맷, 수집 주기, 품질 도구, 린트와 배포 방식은 보류
- 작업 전 project-wiki와 존재하는 경우 `.agents/skills/data/references/index.md`에서 관련 결정만 확인
