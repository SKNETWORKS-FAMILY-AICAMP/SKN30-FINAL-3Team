How it works

기록은 가볍게,
판단은 근거 있게

집크크는 상담 후 남긴 음성메모를 장부 입력 제안으로 바꾸고, 사용자가 저장한 장부와 상담 로그를 바탕으로 매물과 손님의 중개 가능성을 검토합니다.

01 · 상담 기록

음성메모에서 장부 저장까지

AI가 제안하고 사용자가 확인합니다. 검토와 승인 전에는 확정 장부에 자동 저장하지 않습니다.

  1. 1

    음성메모 업로드

    장부의 상세 화면에서 상담 후 작성한 음성 파일을 선택합니다.

  2. 2

    전사와 정보 제안

    STT가 음성을 텍스트로 바꾸고, AI가 빈 장부 필드와 상담 로그 초안을 제안합니다.

  3. 3

    검토 후 저장

    사용자가 제안값을 선택·수정하고 최종 확인한 내용만 장부와 상담 로그에 저장합니다.

02 · 교차 판정

서로 다른 관점을 모아 중개 가능성을 판단

저장 시에는 대상의 포지션 카드까지만 준비합니다. 후보 조회와 판정은 사용자가 교차 판정 버튼을 눌렀을 때 시작합니다.

Property Agent

매물의 구조화 정보와 상담 맥락을 읽고 가격·조건·조정 가능성을 정리합니다.

Customer Agent

손님의 예산과 희망 조건, 상담 로그에 담긴 우선순위와 제약을 정리합니다.

Matching Agent

양측 관점과 결정적으로 추린 후보를 비교해 등급, 근거, 걸림돌과 양보 지점을 제안합니다.

사용자 주도 실행

장부 저장만으로 후보 판정을 자동 실행하지 않습니다. 사용자가 결과를 확인하려는 시점에 직접 실행하고, 각 판단의 근거를 함께 검토합니다.
